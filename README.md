📄 **Project Documentation:** ColddBox presentation included in this repository.

### 🔹 02. Drupal – Web Application Security Testing

An educational project documenting selected security checks related to web application protection.

**Security Topics Explored**
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Open Redirect vulnerabilities
- Access Control and permission checks

**Outcome:** No successful exploitation was observed in the test cases documented. The results are limited to the checks performed and do not establish the overall security of the website.

📄 **Project Documentation:** Drupal Security Testing presentation included in this repository.

## ⚖️ Ethical Use & Cybercrime Awareness

**Cybersecurity knowledge must always be used responsibly.**

These projects are intended for educational purposes, cybersecurity practice, and cybercrime awareness. Security testing should only be conducted on systems you own or have explicit authorization to test, within the permitted scope and applicable rules.

I do not support unauthorized access, data theft, disruption of services, or any malicious use of cybersecurity tools.

---

## 🔐 Disclaimer

The presentations document selected educational security tests and observations. They are not comprehensive security audits, and the results should not be interpreted as proof that any system is completely secure.

All testing claims should reflect the actual work performed and the authorization available for the target environment.
